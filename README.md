# 🌐 Level 5 HTML Projects

This repository contains a collection of basic to intermediate HTML practicals created as part of Level 5 learning.

## 📌 Projects Included

- 📋 **List Practical**  
  Demonstrates all types of HTML lists:
  - Ordered Lists (A, a, I, i, numbers)
  - Unordered Lists
  - Nested Lists  

- 📊 **Table Practical**  
  Covers table creation using:
  - Headings (`<th>`)
  - Rows (`<tr>`)
  - Data cells (`<td>`)
  - Caption (`<caption>`)

- 📞 **Contact Me Form**  
  A complete HTML form including:
  - Text, Email, Password inputs  
  - Radio buttons & Checkboxes  
  - File upload, Date, Time  
  - Dropdown (Select)  
  - Textarea  

- 🎥 **YouTube iframe**  
  Embedding videos using `<iframe>` and understanding:
  - Embed links  
  - Attributes like width, height, allowfullscreen
