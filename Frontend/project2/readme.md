# 🌐 Modern Portfolio Website (HTML + CSS)

This project is an upgraded version of a basic multi-page HTML & CSS website.  
It demonstrates modern UI design, responsive layout, and better structuring techniques.

---

## 🚀 What I Learned & Applied

### 🔹 1. Modern Layout Techniques
- Used **CSS Grid** for creating responsive card layouts
- Implemented proper spacing and alignment using `gap` and `padding`

### 🔹 2. Responsive Design
- Applied **media queries (@media)** to make the website mobile-friendly
- Converted multi-column layout into single column on smaller screens

### 🔹 3. Component-Based Design
- Created reusable components like:
  - Navbar
  - Cards
  - Buttons
- Maintained consistency across multiple pages using a single CSS file

### 🔹 4. Improved UI/UX
- Designed a **dark theme interface**
- Added hover effects using `:hover`
- Used better typography and spacing for readability

### 🔹 5. Advanced CSS Selectors
- Used:
  - **Attribute selectors** → `input[type="text"]`
  - **Pseudo-classes** → `:hover`
  - **nth-child selector** → styling specific cards
  - **Relational selectors** → `.card p`

### 🔹 6. Multi-Page Navigation
- Linked multiple HTML pages:
  - Home
  - Services
  - Contact
- Implemented consistent navigation bar across all pages
