## ⚠️ Common Errors

While working on this project, you may encounter the following common mistakes:

### 1. Incorrect File Linking
- Writing wrong file names in `<a href="">`
- Case sensitivity issues (e.g., `List.html` vs `list.html`)

### 2. Missing Closing Tags
- Forgetting to close tags like `<li>`, `<tr>`, `<td>`, `<form>`
- This can break layout or structure

### 3. Wrong Nesting of Tags
- Placing block elements incorrectly inside inline elements
- Example: `<a><div></div></a>` (not recommended in basic HTML)

### 4. iframe Not Working
- Using normal YouTube link instead of embed link  
  ❌ `watch?v=`  
  ✅ `embed/VIDEO_ID`

### 5. Form Input Issues
- Missing `name` attribute → data won’t be submitted
- Labels not connected properly (`for` and `id` mismatch)

### 6. Table Structure Errors
- Using `<td>` instead of `<th>` for headings
- Unequal number of columns in rows

### 7. Broken Image / File Paths
- Wrong path or missing file
- Not keeping files in correct directories

### 8. Using `<pre>` Instead of `<p>`
- `<pre>` keeps spacing and looks unstructured
- Use `<p>` for normal text

### 9. Forgetting `target="_blank"`
- Links open in same tab instead of new tab

### 10. Not Using Semantic Tags
- Overusing `<div>` instead of:
  - `<header>`
  - `<nav>`
  - `<main>`
  - `<section>`
  - `<footer>`

---

## 💡 Tip
Always test your project in a browser and check for:
- Broken links  
- Layout issues  
- Console errors (if any)
